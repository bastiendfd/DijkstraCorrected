# Security Policy

## Supported versions

Security fixes are considered for the latest code on the `main` branch. This is an educational, non-production project and no support or response-time commitment is made.

## Reporting a vulnerability

Please **do not** open a public issue for a suspected vulnerability. Instead, use GitHub's private vulnerability-reporting feature for this repository, or contact the repository owner through their GitHub profile with:

- a clear description of the issue;
- minimal reproduction steps; and
- potential impact, if known.

Please do not include credentials, API keys, or personal data in a report. The maintainer will acknowledge reports when possible and coordinate a fix or public disclosure as appropriate.
